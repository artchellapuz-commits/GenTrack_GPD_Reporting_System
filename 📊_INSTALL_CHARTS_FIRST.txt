============================================================
INSTALL CHART.JS FIRST
============================================================

Before the plant detail feature can work, you need to install
the charting library.

STEP 1: INSTALL CHART.JS
Run this command in the frontend folder:

cd frontend
npm install chart.js vue-chartjs

Or double-click: INSTALL_CHARTJS.bat

STEP 2: WAIT FOR INSTALLATION
This will take 1-2 minutes to download and install.

STEP 3: TELL ME WHEN DONE
Once installed, let me know and I'll create the plant
detail modal component with charts.

============================================================
WHY CHART.JS?
============================================================

- Most popular charting library for Vue
- Easy to use and customize
- Great performance
- Beautiful default styling
- Supports all chart types we need

============================================================
WHAT YOU'LL GET:
============================================================

After installation, I'll create:
✓ Clickable plant cards
✓ Modal popup with plant details
✓ Generation trend chart (line)
✓ Capacity factor chart (line)
✓ Unit performance chart (bar)
✓ All using REAL data from database
