========================================
HOW TO USE:
========================================

AUTOMATED REPORTS:
  → http://localhost:8080/scheduled-reports
  → Click "Run Now" to generate report immediately
  → Click "History" to see past executions
  → Click "Schedule New Report" to create custom schedule

ADVANCED ANALYTICS:
  → http://localhost:8080/analytics
  → Select analysis type
  → Choose date range and plants
  → Click "Generate Analysis"
  → Export results

PWA INSTALLATION:
  → Open in Chrome browser
  → Click install icon in address bar
  → Click "Install" button
  → App opens in standalone window
