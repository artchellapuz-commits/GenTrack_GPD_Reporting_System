HOW TO USE:
===========

1. Go to "Generate Report" page in the frontend
2. Select one or more plants
3. Choose date range (start and end date)
4. Select report type:
   - "Plant Status Report (PSR)" - Official PSR format
   - "Daily Plant Status Report" - Daily status with capacity and load
5. Click "Generate Report"
6. Excel file downloads automatically:
   - PSR: PLANT_STATUS_YYYYMMDD.xlsx
   - Daily Status: DAILY_PLANT_STATUS_YYYYMMDD.xlsx

REPORT FORMATS:
===============

PSR Report:
- Official Plant Status Report format
- Includes generation data, IPP section, charts
- Matches NPC's PSR REPORT-8AM.xlsx format

Daily Status Report:
- Daily plant status with unit breakdowns
- Rated capacity, dependable capacity, load at 12:00 NN
- Lake elevations (Lanao, Agus forebays, Pulangi IV)
- Capacity comparison chart
- Signature footer
