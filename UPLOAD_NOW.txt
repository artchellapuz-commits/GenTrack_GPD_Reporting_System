================================================================================
                         EXCEL FILE FORMAT
================================================================================

Required columns (case-insensitive):
  - Date
  - Unit Number
  - Generation kWh
  - Operating Hours
  - Availability Hours
  - Forced Outage Hours
  - Scheduled Outage Hours
  - Remarks (optional)

The system automatically converts:
  "Generation kWh" → generation_kwh
  "Unit Number" → unit_number
  etc.

================================================================================
                         IF YOU GET ERRORS
================================================================================

"Missing required columns":
  - Check column headers match exactly
  - Use the sample file as template
  - See EXCEL_FORMAT_GUIDE.md for details

"pandas is required":
  - Run: INSTALL_PANDAS.bat
  - Or: cd backend && venv\Scripts\pip install pandas

"Unit X not found":
  - Check unit numbers match the plant
  - AGUS5 has units 1-2 only
  - Other plants have units 1-4
