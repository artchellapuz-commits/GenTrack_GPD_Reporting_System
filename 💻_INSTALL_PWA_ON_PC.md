# 💻 How to Install PWA on Your PC (Windows)

## Super Simple Steps!

### Method 1: Using the Install Button (Easiest!)

1. **Open Chrome or Edge browser**
   - Chrome is recommended
   - Edge also works great

2. **Go to your website**
   ```
   http://localhost:8080
   ```
   Or if deployed:
   ```
   http://your-server-ip:8080
   ```

3. **Look at the address bar**
   - You'll see a small **install icon** (⊕ or computer icon)
   - It's on the RIGHT side of the address bar
   
   ```
   ┌─────────────────────────────────────────────┐
   │ http://localhost:8080              [⊕] [⋮] │
   └─────────────────────────────────────────────┘
                                          ↑
                                    Click here!
   ```

4. **Click the install icon**
   - A popup will appear

5. **Click "Install"**
   ```
   ┌──────────────────────────────────┐
   │  Install NPC System?             │
   │                                  │
   │  This site can be installed as   │
   │  an app                          │
   │                                  │
   │  [Cancel]  [Install]             │
   └──────────────────────────────────┘
   ```

6. **Done!**
   - The app opens in its own window
   - A shortcut is added to your desktop
   - You can also find it in Start Menu

---

### Method 2: Using Browser Menu

1. **Open Chrome or Edge**

2. **Go to the website**
   ```
   http://localhost:8080
   ```

3. **Click the three dots (⋮) menu**
   - Top right corner of browser

4. **Look for "Install NPC System..." or "Apps"**
   
   **In Chrome:**
   ```
   ⋮ Menu
   ├── New tab
   ├── New window
   ├── ...
   ├── Save and share
   │   └── Install NPC System...  ← Click this!
   └── ...
   ```

   **In Edge:**
   ```
   ⋮ Menu
   ├── New tab
   ├── New window
   ├── ...
   ├── Apps
   │   └── Install this site as an app  ← Click this!
   └── ...
   ```

5. **Click "Install"**

6. **Done!**

## What Happens After Installation?

### You'll Get:

1. **Desktop Shortcut**
   - Icon on your desktop
   - Double-click to open

2. **Start Menu Entry**
   - Search "NPC System" in Start Menu
   - Pin it for quick access

3. **Standalone Window**
   - Opens like a regular program
   - No browser tabs or address bar
   - Clean, focused interface

4. **Taskbar Icon**
   - Pin it to taskbar for even quicker access

## Troubleshooting

### "I don't see the install icon!"

**Possible reasons:**
1. Not using Chrome or Edge
   - **Solution**: Use Chrome or Edge browser

2. Already installed
   - **Solution**: Check Start Menu for "NPC System"

3. Service worker not registered
   - **Solution**: Refresh the page (F5)

4. Using HTTP instead of HTTPS
   - **Solution**: Use `http://localhost:8080` (localhost works)

### "Install option is grayed out"

**Solution:**
- Close all tabs of the website
- Reopen in a new tab
- Try again

### "Can't find the installed app"

**Check these locations:**
1. Desktop (look for icon)
2. Start Menu (search "NPC")
3. Chrome Apps: `chrome://apps`
4. Edge Apps: `edge://apps`

## Uninstalling (if needed)

### Method 1: From the App
1. Open the installed app
2. Click the three dots (⋮) in the app window
3. Select "Uninstall NPC System..."
4. Confirm

### Method 2: From Browser
1. Go to `chrome://apps` (Chrome) or `edge://apps` (Edge)
2. Right-click "NPC System"
3. Select "Remove from Chrome/Edge"
4. Confirm

### Method 3: Windows Settings
1. Open Windows Settings
2. Go to Apps
3. Find "NPC System"
4. Click Uninstall
