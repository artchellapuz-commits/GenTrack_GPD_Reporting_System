📋 WHAT IT DOES:
   Automatically scrapes the NPC website for Agus-Pulangi plant status
   - Plant names
   - Water levels
   - Generation status
   - Current generation (MW)
   - Capacity (MW)

💡 USAGE EXAMPLES
═══════════════════════════════════════════════════════════════════════

Example 1: Basic Usage
────────────────────────────────────────────────────────────────────────
python scrape_npc_plant_status.py

Example 2: From Python Code
────────────────────────────────────────────────────────────────────────
from scrape_npc_plant_status import NPCPlantStatusScraper

scraper = NPCPlantStatusScraper()
result = scraper.scrape()

if result['success']:
    for plant in result['plants']:
        print(f"{plant['plant_name']}: {plant['generation_status']}")

Example 3: Custom Timeout
────────────────────────────────────────────────────────────────────────
scraper = NPCPlantStatusScraper(timeout=60)
result = scraper.scrape()

⚠️  IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════

1. Requires internet connection
2. NPC website must be accessible
3. Website structure may change (requires updates)
4. Don't scrape too frequently (recommended: every 15-30 min)
5. Check NPC's terms of service

═══════════════════════════════════════════════════════════════════════
🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: "Failed to connect"
Solution: Check internet connection, verify NPC website is up

Problem: "No plant data found"
Solution: Website structure changed, update URLs in script

Problem: "Timeout error"
Solution: Increase timeout value

Problem: "SSL certificate error"
Solution: Update requests library or disable SSL verification
