   ⚡ FIX: 401 UNAUTHORIZED ERRORS

You're getting 401 errors because your login tokens are invalid
or expired. Here's how to fix it:

═══════════════════════════════════════════════════════════════
   SOLUTION 1: CLEAR CACHE AND LOGIN AGAIN (RECOMMENDED)
═══════════════════════════════════════════════════════════════

1. Press F12 to open Developer Tools
2. Go to "Application" tab (Chrome) or "Storage" tab (Firefox)
3. Click "Local Storage" → "http://localhost:8080"
4. Click "Clear All" button
5. Close Developer Tools
6. Refresh the page (F5)
7. You'll be redirected to login page
8. Login with:
   Username: admin
   Password: admin123

═══════════════════════════════════════════════════════════════
   SOLUTION 2: QUICK CONSOLE FIX
═══════════════════════════════════════════════════════════════

1. Press F12
2. Go to "Console" tab
3. Paste this code:

localStorage.clear();
location.href = '/login';

4. Press Enter
5. Login again

═══════════════════════════════════════════════════════════════
   SOLUTION 3: RESTART FRONTEND SERVER
═══════════════════════════════════════════════════════════════

The auth.js file was just updated to prevent infinite loops.
You need to restart the frontend:

1. Stop frontend server (Ctrl+C)
2. Start it again:
   cd frontend
   npm run serve
3. Clear browser cache (Ctrl+Shift+R)
4. Login again

═══════════════════════════════════════════════════════════════
   WHY THIS HAPPENED
═══════════════════════════════════════════════════════════════

The 401 errors mean:
- Your access token expired
- The refresh token also expired or is invalid
- The system tried to refresh but failed
- This created a loop of failed refresh attempts

The fix I just applied prevents the infinite loop and will
redirect you to login when tokens are invalid.
