========================================
APPROVAL WORKFLOW
========================================

1. OPERATOR submits nomination
   Status: DRAFT → SUBMITTED
   
2. MANAGER sees it in Approval Queue
   Pending count increases
   
3. MANAGER reviews and approves
   Status: SUBMITTED → APPROVED
   
4. OPERATOR receives email notification
   "Your nomination has been approved"
   
5. System logs the approval
   Audit trail: Who approved, when, what

========================================
TROUBLESHOOTING
========================================

Problem: Don't see Approval Queue menu
Solution: 
- Check you're logged in as manager1 or admin
- Restart frontend after code changes
- Clear browser cache (Ctrl+Shift+R)

Problem: Still see approve button as operator
Solution:
- Logout and login again (refresh user data)
- Clear localStorage
- Hard reload browser

Problem: Approval Queue page is empty
Solution:
- Make sure there are SUBMITTED nominations
- Check filters (should show status: SUBMITTED)
- Refresh the page

Problem: Cannot access /approval-queue
Solution:
- Check you have manager or admin role
- Check browser console for errors
- Verify backend is running
