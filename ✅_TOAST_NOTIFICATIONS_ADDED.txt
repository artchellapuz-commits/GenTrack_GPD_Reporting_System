WHEN TOASTS ARE SHOWN:
=======================

Success Toasts:
- Report created successfully
- Report updated successfully
- Report status changed (paused/activated)
- Report generated successfully
- Report deleted successfully

Error Toasts:
- Failed to save report
- Failed to update status
- Failed to run report
- Failed to delete report

TOAST vs MODAL:
===============

Toasts (Quick Feedback):
- Success messages
- Status updates
- Quick confirmations
- Non-blocking notifications

Modals (Important Actions):
- Delete confirmation (requires user decision)
- Error details (when user needs to read carefully)
- Complex messages with HTML formatting

USAGE:
======

Show Toast:
```javascript
showToast('success', 'Title', 'Message', 4000);
showToast('error', 'Error', 'Something went wrong');
showToast('warning', 'Warning', 'Please check this');
showToast('info', 'Info', 'Did you know?');
```

Parameters:
- type: 'success', 'error', 'warning', 'info'
- title: Toast title (bold text)
- message: Toast message (regular text)
- duration: Auto-dismiss time in ms (default: 4000)

TECHNICAL DETAILS:
==================

State Variables:
- toasts: Array of toast objects
- toastIdCounter: Unique ID generator

Toast Object:
{
  id: number,
  type: 'success' | 'error' | 'warning' | 'info',
  title: string,
  message: string
}

Functions:
- showToast(type, title, message, duration): Add new toast
- removeToast(id): Remove specific toast

CSS Classes:
- .toast-container: Container for all toasts
- .toast: Individual toast
- .toast-success/error/warning/info: Type-specific styling
- .toast-icon: Icon container
- .toast-content: Text content
- .toast-title: Bold title
- .toast-message: Regular message
- .toast-close: Close button
