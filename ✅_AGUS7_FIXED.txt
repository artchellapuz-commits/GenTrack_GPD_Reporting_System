============================================================
AGUS7 FIXED - CSS HEIGHT ISSUE RESOLVED
============================================================

THE PROBLEM:
The dropdown parent container had max-height: 400px
The dropdown-options had max-height: 450px
The parent was cutting off the bottom, hiding AGUS7

THE FIX:
Changed parent container max-height from 400px to 500px
Now all 6 plants fit comfortably with room for the search box

============================================================
TO APPLY THE FIX:
============================================================

1. STOP FRONTEND SERVER
   - Go to frontend terminal
   - Press Ctrl+C

2. START FRONTEND SERVER
   - Run: npm run serve
   - Wait for "Compiled successfully"

3. REFRESH BROWSER
   - Press F5 or Ctrl+R
   - Or close and reopen the tab

4. TEST THE DROPDOWN
   - Click on "Select Hydro-Electric Power Plant"
   - Scroll to the bottom
   - AGUS7 should now be visible!
