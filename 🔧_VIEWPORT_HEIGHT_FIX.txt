VIEWPORT HEIGHT FIX - SHOULD SHOW ALL PLANTS NOW
============================================================

THE ISSUE:
Fixed pixel heights (650px, 550px) weren't working because
the dropdown was still being cut off by something.

THE NEW APPROACH:
Use viewport-relative height (80vh = 80% of screen height)
This adapts to any screen size and ensures plenty of room.

============================================================
CHANGES MADE:
============================================================

1. Parent container (.custom-select-dropdown):
   BEFORE: max-height: 650px
   AFTER:  max-height: 80vh (80% of viewport height)

2. Options container (.dropdown-options):
   BEFORE: max-height: 550px
   AFTER:  flex: 1 (takes all available space)

This means:
- Dropdown can be as tall as 80% of your screen
- Options container fills all available space
- All 6 plants should definitely fit!
