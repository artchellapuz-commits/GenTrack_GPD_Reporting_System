========================================
FIX "RUN NOW" BUTTON ERROR
========================================

PROBLEM:
When clicking "Run Now" button, you get:
"ReportExecution() got an unexpected keyword argument 'approved' and 'report_type'"

ROOT CAUSE:
Python is using cached bytecode (.pyc files) with an old version of the ReportExecution model.
The actual code is correct, but Python loads the old cached version.

========================================
SOLUTION (Choose ONE method):
========================================

METHOD 1: AUTOMATED FIX (RECOMMENDED)
--------------------------------------
1. Double-click: FIX_RUN_NOW_ERROR.bat
2. Wait for it to complete
3. Restart backend server:
   - Press Ctrl+C in backend terminal
   - Run START_BACKEND.bat again
4. Refresh Scheduled Reports page
5. Click "Run Now" button

METHOD 2: MANUAL FIX
--------------------
1. Stop backend server (Ctrl+C)

2. Clear Python cache:
   cd npc-reporting-system\backend
   for /d /r . %d in (__pycache__) do @if exist "%d" rd /s /q "%d"
   del /s /q *.pyc

3. Verify model (optional):
   python verify_report_execution.py

4. Restart backend:
   python manage.py runserver

5. Test "Run Now" button

========================================
TECHNICAL DETAILS:
========================================

The ReportExecution model should have these fields:
- id
- scheduled_report (ForeignKey)
- status
- started_at
- completed_at
- duration_seconds
- file_path
- file_size
- records_processed
- error_message
- recipients_sent
- recipients_failed

It should NOT have:
- approved (this was from a different model)
- report_type (this is in ScheduledReport, not ReportExecution)

The error happens because Python's import cache has an old version
where these fields existed. Clearing cache forces Python to reload
the correct model definition.
