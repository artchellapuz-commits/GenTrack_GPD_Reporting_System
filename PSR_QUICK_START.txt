📋 WHAT IS PSR?

Plant Status Report - Official format for Mindanao Generation
(PSALM Portfolio) showing plant status, capacity, load, and remarks.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🚀 HOW TO GENERATE (3 WAYS):

┌──────────────────────────────────────────────────────────────┐
│ METHOD 1: Frontend (Easiest)                                 │
└──────────────────────────────────────────────────────────────┘

1. Open: http://localhost:8080
2. Click "Generate Report" in sidebar
3. Select plants: AGUS1, AGUS2, AGUS4, AGUS5, AGUS6, AGUS7, PULANGI4
4. Choose date (single day recommended)
5. Select "Plant Status Report (PSR)"
6. Click "Generate Report"
7. File downloads as: PSR_REPORT_YYYYMMDD.xlsx

┌──────────────────────────────────────────────────────────────┐
│ METHOD 2: Test Script                                        │
└──────────────────────────────────────────────────────────────┘

Run: python test_psr_generation.py

This will:
- Find available data
- Generate PSR report
- Show file location
- Display preview

┌──────────────────────────────────────────────────────────────┐
│ METHOD 3: Quick Access                                       │
└──────────────────────────────────────────────────────────────┘

Double-click: OPEN_PSR_REPORT.bat

Opens the most recent PSR report in Excel

📊 WHAT'S INCLUDED:

✓ Header: "MINDANAO GENERATION (PSALM PORTFOLIO)"
✓ Date: "as of 0800H [Day, Date Month Year]"
✓ Plant sections:
  • AGUS 1 (2 units @ 40 MW)
  • AGUS 2 (3 units @ 60 MW)
  • AGUS 4 (3 units @ 52.7 MW)
  • AGUS 5 (2 units @ 27.5 MW)
  • AGUS 6 (5 units, varying capacity)
  • AGUS 7 (2 units @ 27 MW)
  • TOTAL AGUS
  • PULANGI IV (3 units @ 85 MW)
  • TOTAL HYDRO
✓ Columns: Plant Name, Capacity, Nominated, Available, 
           Outflow, Load, Remarks
✓ Footer: Signatures (DRB CAIRO, JMM MATA, DB ESMADE JR.)
✓ Formatting: Colors, fonts, merged cells - exact match!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 TIPS:

• Use single day for PSR (not date range)
• Select all AGUS and PULANGI4 plants
• Generated file matches template exactly
• Data comes from GenerationReport table
• Same data as Dashboard and View Reports
