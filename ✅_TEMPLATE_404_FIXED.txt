ERROR:
  GET http://localhost:8000/api/api/uploaded-files/download-template/water-nomination/
  404 (Not Found)

PROBLEM:
  Double /api/api/ in the URL causing 404 error

ROOT CAUSE:
  The VUE_APP_API_URL environment variable already includes '/api' at the end,
  but the code was adding '/api/' again, resulting in '/api/api/'.

SOLUTION:
  Changed the URL construction to not add '/api' prefix since it's already
  included in the base URL.

───────────────────────────────────────────────────────────────────────────────
✅ WHAT WAS FIXED
───────────────────────────────────────────────────────────────────────────────

FILE: frontend/src/components/UploadExcel.vue

BEFORE (BROKEN):
  const baseURL = process.env.VUE_APP_API_URL || 'http://localhost:8000';
  const url = `${baseURL}/api/uploaded-files/download-template/${templateType}/`;
  
  Result: http://localhost:8000/api/api/uploaded-files/... ❌

AFTER (FIXED):
  const baseURL = process.env.VUE_APP_API_URL || 'http://localhost:8000/api';
  const url = `${baseURL}/uploaded-files/download-template/${templateType}/`;
  
  Result: http://localhost:8000/api/uploaded-files/... ✅

───────────────────────────────────────────────────────────────────────────────
💡 WHY THIS HAPPENED
───────────────────────────────────────────────────────────────────────────────

The api.js service file defines:
  const API_BASE_URL = process.env.VUE_APP_API_URL || 'http://localhost:8000/api';
                                                                              ^^^^
                                                                         Already has /api

So when we used:
  const baseURL = process.env.VUE_APP_API_URL || 'http://localhost:8000';
  const url = `${baseURL}/api/uploaded-files/...`;
                          ^^^^
                     Adding /api again

We got: http://localhost:8000/api/api/uploaded-files/... (WRONG)

Now we use:
  const baseURL = process.env.VUE_APP_API_URL || 'http://localhost:8000/api';
  const url = `${baseURL}/uploaded-files/...`;
                     No /api prefix

We get: http://localhost:8000/api/uploaded-files/... (CORRECT)
