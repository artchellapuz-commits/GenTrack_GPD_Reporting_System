  ✅ TEMPLATE DOWNLOAD BUTTONS - FIXED
═══════════════════════════════════════════════════════════════════════════════

PROBLEM:
  Clicking template download buttons navigated to 404 page instead of
  downloading the Excel file.

ROOT CAUSE:
  The downloadTemplate() method was creating a simple <a> link with href
  pointing to the API endpoint. When clicked, the browser tried to navigate
  to that URL instead of downloading the file.

SOLUTION:
  Changed the download method to:
  1. Use fetch() to get the file from API
  2. Convert response to Blob
  3. Create object URL from Blob
  4. Trigger download programmatically
  5. Clean up object URL after download

💡 TECHNICAL DETAILS
───────────────────────────────────────────────────────────────────────────────

NEW DOWNLOAD FLOW:
  1. User clicks template button
  2. Frontend calls: fetch(API_URL/download-template/TYPE/)
  3. Backend returns Excel file as binary data
  4. Frontend converts to Blob
  5. Creates temporary object URL
  6. Triggers download via programmatic click
  7. Cleans up object URL

WHY THIS WORKS:
  - fetch() gets the file without navigation
  - Blob handles binary Excel data
  - Object URL creates downloadable link
  - Programmatic click triggers download
  - No page navigation occurs
