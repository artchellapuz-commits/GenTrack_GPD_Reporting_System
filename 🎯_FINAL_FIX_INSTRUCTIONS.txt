========================================
WHY THIS HAPPENS:
========================================

Python compiles .py files to .pyc bytecode for speed.
When models change, old .pyc files may still load.
This causes "unexpected keyword argument" errors.
Clearing cache forces Python to recompile with new code.

========================================
TECHNICAL NOTES:
========================================

ReportExecution model has these fields:
  - scheduled_report (ForeignKey)
  - status
  - started_at, completed_at
  - duration_seconds
  - file_path, file_size
  - records_processed
  - error_message
  - recipients_sent, recipients_failed

It does NOT have:
  - approved (wrong model)
  - report_type (in ScheduledReport, not here)

The error means Python is trying to create ReportExecution
with fields that don't exist in the current model definition.
