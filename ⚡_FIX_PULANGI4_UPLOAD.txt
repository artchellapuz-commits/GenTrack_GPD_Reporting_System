========================================
⚡ FIX: Pulangi 4 Upload Error
========================================

ERROR: "Upload failed" when uploading Excel for Pulangi 4

SOLUTION (2 STEPS):
===================

STEP 1: RESTART BACKEND SERVER ⭐ MOST IMPORTANT
------------------------------------------------
The backend server needs to be restarted to load Pulangi 4.

Option A - Using Batch File:
1. Close the backend terminal window
2. Double-click: START_BACKEND.bat

Option B - Manual:
1. Press Ctrl+C in backend terminal to stop
2. Run these commands:
   cd npc-reporting-system\backend
   venv\Scripts\activate
   python manage.py runserver


STEP 2: USE CORRECT EXCEL FORMAT
---------------------------------
Pulangi 4 has 3 UNITS (not 4 like Agus plants!)

✅ CORRECT: 3 units (Unit 1, 2, 3)
❌ WRONG: 4 units (Unit 1, 2, 3, 4)

Use the sample file: SAMPLE_PULANGI4.xlsx

Required columns:
- Date (YYYY-MM-DD format)
- Unit Number (1, 2, or 3 only)
- Generation kWh
- Operating Hours
- Availability Hours
- Forced Outage Hours
- Scheduled Outage Hours


QUICK TEST:
===========
1. Restart backend server (see Step 1)
2. Go to Upload Excel page
3. Select "Pulangi 4 Hydroelectric Plant"
4. Upload: SAMPLE_PULANGI4.xlsx
5. Should see: "21 records imported successfully"


IF SAMPLE FILE DOESN'T EXIST:
==============================
Run this command:
  cd npc-reporting-system
  python CREATE_PULANGI4_SAMPLE.py


COMMON MISTAKES:
================
❌ Backend not restarted after installing Pulangi 4
❌ Excel file has 4 units instead of 3
❌ Unit numbers are 0, 4, or 5 (should be 1, 2, 3)
❌ Wrong column names
❌ Wrong date format (use YYYY-MM-DD)


VERIFICATION:
=============
After successful upload:
✓ Message: "X records imported successfully"
✓ File appears in "Recent Uploads"
✓ Status: COMPLETED
✓ Pulangi 4 shows data in Dashboard
