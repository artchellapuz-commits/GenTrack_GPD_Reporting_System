┌───────────────────────────────────────────────────────────────┐
│ ACCESS                                                         │
├───────────────────────────────────────────────────────────────┤
│ URL: http://localhost:8080/user-management                    │
│ Who: Admin users only                                          │
│ Location: Sidebar → Administration → User Management          │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ QUICK ACTIONS                                                  │
├───────────────────────────────────────────────────────────────┤
│ CREATE USER:    Click "Create New User" button                │
│ EDIT USER:      Click ✏️ icon in Actions column              │
│ TOGGLE STATUS:  Click 🔒/✓ icon in Actions column            │
│ DELETE USER:    Click 🗑️ icon in Actions column              │
│ SEARCH:         Type in search box                             │
│ FILTER:         Use Role or Status dropdowns                   │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ USER ROLES                                                     │
├───────────────────────────────────────────────────────────────┤
│ VIEWER    → View reports only                                 │
│ OPERATOR  → Upload data, submit nominations                   │
│ MANAGER   → Approve nominations, manage data                  │
│ ADMIN     → Full access, manage users                         │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ CREATE USER FORM                                               │
├───────────────────────────────────────────────────────────────┤
│ Username *        → Must be unique, cannot change later        │
│ Email             → Optional but recommended                   │
│ Password *        → Required for new users                     │
│ Confirm Password* → Must match password                        │
│ Role *            → Select from dropdown                       │
│ Active User       → Check to allow login                       │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ STATISTICS CARDS                                               │
├───────────────────────────────────────────────────────────────┤
│ 👥 Total Users    → All users in system                       │
│ ✓ Active Users    → Users who can login                       │
│ 🛡️ Admins         → Admin role users                          │
│ 💼 Managers       → Manager role users                        │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ COMMON TASKS                                                   │
├───────────────────────────────────────────────────────────────┤
│ Add Operator:                                                  │
│   1. Click "Create New User"                                   │
│   2. Enter username (e.g., operator_agus1)                     │
│   3. Set email and password                                    │
│   4. Select "Operator" role                                    │
│   5. Check "Active User"                                       │
│   6. Click "Create User"                                       │
│                                                                 │
│ Promote to Manager:                                            │
│   1. Find user in table                                        │
│   2. Click edit icon                                           │
│   3. Change role to "Manager"                                  │
│   4. Click "Update User"                                       │
│                                                                 │
│ Disable Access:                                                │
│   1. Find user in table                                        │
│   2. Click deactivate icon                                     │
│   3. Confirm action                                            │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ KEYBOARD SHORTCUTS                                             │
├───────────────────────────────────────────────────────────────┤
│ Tab          → Navigate between fields                         │
│ Enter        → Submit form                                     │
│ Esc          → Close modal                                     │
│ Ctrl+F       → Focus search box (browser default)              │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                │
├───────────────────────────────────────────────────────────────┤
│ Can't access page?                                             │
│   → Check you're logged in as admin                            │
│                                                                 │
│ Can't create user?                                             │
│   → Username might already exist                               │
│   → Check all required fields are filled                       │
│                                                                 │
│ User can't login?                                              │
│   → Check "Active" status is enabled                           │
│   → Verify password was set correctly                          │
│                                                                 │
│ Changes not saving?                                            │
│   → Check network connection                                   │
│   → Look for error messages                                    │
│   → Check browser console (F12)                                │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ BEST PRACTICES                                                 │
├───────────────────────────────────────────────────────────────┤
│ ✓ Always add email addresses                                  │
│ ✓ Use descriptive usernames                                   │
│ ✓ Assign minimum required role                                │
│ ✓ Deactivate instead of delete                                │
│ ✓ Review users regularly                                      │
│ ✓ Use strong passwords                                        │
│ ✓ Test new accounts after creation                            │
└───────────────────────────────────────────────────────────────┘

┌───────────────────────────────────────────────────────────────┐
│ API ENDPOINTS (for developers)                                 │
├───────────────────────────────────────────────────────────────┤
│ GET    /api/users/      → List all users                      │
│ POST   /api/users/      → Create user                         │
│ PUT    /api/users/{id}/ → Update user                         │
│ PATCH  /api/users/{id}/ → Partial update                      │
│ DELETE /api/users/{id}/ → Delete user                         │
