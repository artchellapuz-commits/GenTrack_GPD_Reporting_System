OPTIONAL SETUP:
---------------

EMAIL (for automated reports):
1. Edit backend/.env file
2. Add:
   EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
   EMAIL_HOST_USER=your-email@gmail.com
   EMAIL_HOST_PASSWORD=your-app-password

TASK SCHEDULER (for automated execution):
1. Open Windows Task Scheduler
2. Create task to run daily
3. Program: python
4. Arguments: manage.py run_scheduled_reports
5. Start in: C:\path\to\backend

PWA ICONS:
1. Create icons in frontend/public/icons/
2. Sizes: 72, 96, 128, 144, 152, 192, 384, 512
