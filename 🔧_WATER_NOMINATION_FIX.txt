PROBLEM IDENTIFIED:
------------------
The 400 Bad Request error was caused by a UNIQUE CONSTRAINT violation.

Error Message:
"The fields plant, nomination_date, nomination_type must make a unique set."

This means you were trying to create a water nomination that ALREADY EXISTS
in the database with the same:
- Plant
- Date  
- Nomination Type (DAY_AHEAD, HOUR_AHEAD, or REAL_TIME)

HOW TO TEST THE APPROVAL QUEUE:
--------------------------------

Now that the error is fixed, here's how to create SUBMITTED nominations
for testing the Approval Queue:

STEP 1: Delete Existing Duplicates (if any)
   - Go to Water Nomination page
   - Find any DRAFT nominations you don't need
   - Click the DELETE button (red trash icon)

STEP 2: Create a New Nomination
   - Click "New Nomination" button
   - Select a plant
   - Choose a date that doesn't have a nomination yet
   - Fill in hourly values (or use Quick Fill buttons)
   - Click "Create"

STEP 3: Submit for Approval
   - Find the newly created DRAFT nomination
   - Click the "Submit" button (green send icon)
   - Confirm the submission

STEP 4: Check Approval Queue
   - Login as Manager or Admin
   - Go to "Approval Queue" from the menu
   - You should now see the SUBMITTED nomination
   - Click "Approve" or "Reject"

WHY APPROVAL QUEUE WAS EMPTY:
------------------------------

The Approval Queue ONLY shows nominations with status = "SUBMITTED"

Your existing nominations were all "APPROVED" already, so they don't
appear in the queue. This is correct behavior!

The queue is for PENDING approvals only.

UNIQUE CONSTRAINT RULES:
-------------------------

You CANNOT have two nominations with the same:
- Plant + Date + Type

Examples:
❌ AGUS1 + 2026-02-20 + DAY_AHEAD (already exists)
❌ AGUS1 + 2026-02-20 + DAY_AHEAD (duplicate - will fail!)

✅ AGUS1 + 2026-02-20 + DAY_AHEAD (original)
✅ AGUS1 + 2026-02-20 + HOUR_AHEAD (different type - OK!)
✅ AGUS1 + 2026-02-21 + DAY_AHEAD (different date - OK!)
✅ AGUS2 + 2026-02-20 + DAY_AHEAD (different plant - OK!)
