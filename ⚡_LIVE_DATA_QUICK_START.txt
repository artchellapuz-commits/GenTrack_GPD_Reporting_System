  ⚡ NPC LIVE DATA - QUICK START
═══════════════════════════════════════════════════════════════════════

WHAT THIS DOES:
───────────────────────────────────────────────────────────────────────
Connects to NPC's live data systems and automatically syncs real-time
plant data (generation, water levels, status) to your database.

═══════════════════════════════════════════════════════════════════════
📋 BEFORE YOU START
═══════════════════════════════════════════════════════════════════════

YOU NEED FROM NPC:
✓ API URL (e.g., https://api.napocor.gov.ph/v1)
✓ API Key or Username/Password
✓ API Documentation (optional but helpful)

CONTACT:
→ NPC IT Department
→ NPC Operations Team
→ Request "API access for Agus-Pulangi plant data"

═══════════════════════════════════════════════════════════════════════
⚡ SETUP (3 STEPS)
═══════════════════════════════════════════════════════════════════════

STEP 1: Run Setup
───────────────────────────────────────────────────────────────────────
Double-click: ⚡_SETUP_LIVE_DATA.bat

STEP 2: Add Credentials
───────────────────────────────────────────────────────────────────────
Edit: backend\.env.npc

Add your NPC credentials:
  NPC_API_URL=https://api.napocor.gov.ph/v1
  NPC_API_KEY=your_api_key_here

STEP 3: Test Connection
───────────────────────────────────────────────────────────────────────
cd backend
python manage.py fetch_live_data --test

═══════════════════════════════════════════════════════════════════════
🚀 USAGE
═══════════════════════════════════════════════════════════════════════

FETCH LIVE DATA:
───────────────────────────────────────────────────────────────────────
Double-click: ⚡_FETCH_LIVE_DATA.bat

OR COMMAND LINE:
───────────────────────────────────────────────────────────────────────
# Fetch all plants
python manage.py fetch_live_data

# Fetch specific plants
python manage.py fetch_live_data --plants AGUS1,AGUS2

# Fetch and sync to database
python manage.py fetch_live_data --sync

# Save to file
python manage.py fetch_live_data --output live_data.json
