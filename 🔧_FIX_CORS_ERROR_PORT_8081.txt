ERROR YOU'RE SEEING:
"Access to XMLHttpRequest at 'http://localhost:8000/api/plants/' 
from origin 'http://localhost:8081' has been blocked by CORS policy"

WHAT THIS MEANS:
- Your frontend is running on port 8081
- Backend only allows requests from port 8080
- Browser blocks the request for security

THE FIX (ALREADY APPLIED):
✅ Added port 8081 to Django CORS settings
✅ File: backend/npc_reporting/settings.py

WHAT YOU NEED TO DO:
1. RESTART THE BACKEND SERVER
   - Stop the backend (Ctrl+C in backend terminal)
   - Start it again: python manage.py runserver
   
2. HARD REFRESH THE FRONTEND
   - Press: Ctrl + Shift + R
   - Or: Ctrl + F5

WHY RESTART IS NEEDED:
Django only reads settings.py when it starts. Changes to 
CORS_ALLOWED_ORIGINS won't take effect until you restart.

CURRENT CORS SETTINGS:

5. Go to frontend browser
6. Press Ctrl+Shift+R to hard refresh
7. Check if error is gone
