1. ⚠️ [Deprecation] DOMNodeInsertedIntoDocument
═══════════════════════════════════════════════════════════════════════

WHAT IT MEANS:
A third-party library (Chart.js or PrimeVue) is using an old DOM event
that browsers plan to remove in the future.

WHY IT HAPPENS:
The library hasn't updated to use the newer MutationObserver API yet.

IMPACT:
✓ NONE - Just a warning
✓ App works perfectly
✓ No performance issues
✓ No functionality broken

SHOULD YOU FIX IT?
❌ NO - You can't fix it (it's in the library code)
✓ Library maintainers will fix it in future updates

ACTION NEEDED:
None. Completely safe to ignore.

2. 🔴 Failed to load resource: icons/icon-144x144.png (404)
═══════════════════════════════════════════════════════════════════════

WHAT IT MEANS:
The browser is trying to load PWA icon files that don't exist.

WHY IT HAPPENS:
We added PWA support but haven't created the icon files yet.

IMPACT:
⚠️ PWA installation won't work
✓ App still works normally
✓ All features functional
✓ Just can't install to home screen

FILES MISSING:
- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

QUICK FIX (Stop 404 errors):
> python CREATE_PLACEHOLDER_ICONS.py

This creates temporary SVG icons.

PROPER FIX (For PWA installation):
1. Go to: https://www.pwabuilder.com/imageGenerator
2. Upload your NPC logo (512x512 recommended)
3. Click "Generate"
4. Download the ZIP file
5. Extract to: frontend/public/icons/
6. Refresh browser

MANUAL CREATION:
If you have image editing software:
1. Create 512x512 PNG with your logo
2. Resize to each size needed
3. Save as icon-{size}x{size}.png
4. Place in frontend/public/icons/

3. 🔴 Failed to load: :8000/api/generation... (ERR_CONNECTION_REFUSED)
═══════════════════════════════════════════════════════════════════════

WHAT IT MEANS:
Frontend is trying to connect to backend, but backend is not running.

WHY IT HAPPENS:
Backend server (Django) is not started on port 8000.

IMPACT:
🔴 CRITICAL - App won't work
🔴 No data will load
🔴 Dashboard will be empty
🔴 All API calls fail

FIX (Start Backend):
> cd backend
> python manage.py runserver

Or use:
> START_BACKEND.bat

VERIFY IT'S RUNNING:
Open in browser: http://localhost:8000/admin
Should see: Django admin login page

IF PORT 8000 IS BUSY:
Check what's using it:
> netstat -ano | findstr :8000

Kill the process:
> taskkill /PID <process_id> /F

Then start backend again.

USE DIFFERENT PORT:
> python manage.py runserver 8001

Then update frontend/.env:
VUE_APP_API_URL=http://localhost:8001

COMMON CAUSES:
- Forgot to start backend
- Backend crashed
- Port already in use
- Database not migrated

TROUBLESHOOTING:
If backend won't start:

1. Check database:
   > python manage.py migrate

2. Check for errors:
   > python manage.py check

3. Test database connection:
   > python manage.py shell
   >>> from reports.models import Plant
   >>> Plant.objects.count()

4. Check requirements:
   > pip install -r requirements.txt

4. 🔴 Error loading overall stats: AxiosError: Network Error
═══════════════════════════════════════════════════════════════════════

WHAT IT MEANS:
Same as #3 - backend not running or not reachable.

WHY IT HAPPENS:
Frontend can't connect to backend API endpoints.

IMPACT:
🔴 Dashboard stats won't load
🔴 Charts will be empty
🔴 Data tables won't populate

FIX:
Same as #3 - start the backend server.

ADDITIONAL CHECKS:
1. Check .env file exists:
   frontend/.env should contain:
   VUE_APP_API_URL=http://localhost:8000

2. Check CORS settings:
   backend/npc_reporting/settings.py should have:
   CORS_ALLOWED_ORIGINS = [
       "http://localhost:8080",
       "http://localhost:8081",
   ]

3. Check network tab in browser:
   - Open DevTools (F12)
   - Go to Network tab
   - Refresh page
   - Look for failed requests
   - Check request URL is correct
