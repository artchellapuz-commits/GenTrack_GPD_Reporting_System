⚡ QUICK FIX - DO THIS NOW

The "Run Now" button IS in the code, but the page shows "No scheduled reports yet" 
because the API call is failing or returning empty data.

═══════════════════════════════════════════════════════════════

STEP 1: Open Browser Console
─────────────────────────────
1. Press F12
2. Click "Console" tab
3. Refresh the page
4. Look for messages starting with "Loading reports from:"

═══════════════════════════════════════════════════════════════

STEP 2: Check What You See
─────────────────────────────

SCENARIO A: You see "Loading reports from: http://localhost:8000/api/scheduled-reports/"
           followed by data
           → Good! Reports are loading. Tell me what the data shows.

SCENARIO B: You see "Failed to load reports: Error: Network Error"
           → Backend not running. Run: START_BACKEND.bat

SCENARIO C: You see "Failed to load reports: 401"
           → Not logged in. Go to /login first.

SCENARIO D: You see "Response data: []" (empty array)
           → Database is empty. Need to create reports.

═══════════════════════════════════════════════════════════════

STEP 3: If Database is Empty (Scenario D)
─────────────────────────────────────────

Run this in backend terminal:

cd backend
python manage.py shell

Then paste this:

from reports.models_scheduled import ScheduledReport
from django.contrib.auth.models import User

user = User.objects.first()

# Create 3 test reports
ScheduledReport.objects.create(
    name="Daily Generation Report",
    report_type="GENERATION_SUMMARY",
    frequency="DAILY",
    schedule_time="08:00",
    format="EXCEL",
    date_range_days=30,
    status="ACTIVE",
    created_by=user
)

ScheduledReport.objects.create(
    name="Weekly Capacity Report",
    report_type="CAPACITY_FACTOR",
    frequency="WEEKLY",
    schedule_time="09:00",
    format="PDF",
    date_range_days=7,
    status="ACTIVE",
    created_by=user
)

ScheduledReport.objects.create(
    name="Monthly Performance",
    report_type="PERFORMANCE_METRICS",
    frequency="MONTHLY",
    schedule_time="10:00",
    format="BOTH",
    date_range_days=30,
    status="PAUSED",
    created_by=user
)

print("✅ 3 reports created!")
exit()

Then refresh the browser page.
