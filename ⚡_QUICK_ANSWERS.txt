========================================
CURRENT WORKFLOW
========================================

OPERATOR:
1. Submits water nomination
2. Status: DRAFT → SUBMITTED
3. Waits for manager approval

MANAGER:
1. Sees nomination in list (status: SUBMITTED)
2. Clicks "Approve" button (if they can see it)
3. Backend checks permission
4. If allowed: Status → APPROVED
5. Email sent to operator

PROBLEM:
- Operator also sees "Approve" button (shouldn't!)
- No dedicated approval queue page
- Manager has to scroll through all nominations

========================================
HOW PERMISSIONS WORK
========================================

Backend (models.py):
--------------------
def can_approve_data(self):
    return self.role in ['MANAGER', 'ADMIN']

Result:
- VIEWER: False
- OPERATOR: False
- MANAGER: True
- ADMIN: True

Frontend (should be):
---------------------
<button v-if="canApproveData()">
  Approve
</button>

Currently missing the v-if check!
