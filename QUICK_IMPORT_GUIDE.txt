========================================
NPC HISTORICAL DATA IMPORT - QUICK GUIDE
========================================

STEP 1: PREPARE YOUR FILES
---------------------------
Place these Excel files in the 'backend' folder:
  ✓ 0PLANT DEPCAP.xlsx (Plant capacity data)
  ✓ 1DATA APAO.xlsx (Historical operational data)

STEP 2: RUN THE IMPORT
----------------------
Double-click: IMPORT_HISTORICAL_DATA.bat

OR use command line:
  cd backend
  venv\Scripts\activate
  python manage.py migrate
  python manage.py import_historical_data --capacity "0PLANT DEPCAP.xlsx" --historical "1DATA APAO.xlsx"

STEP 3: VERIFY IMPORT
---------------------
Check the API endpoints:
  • Historical Data: http://localhost:8000/api/historical-data/
  • Plant Capacity: http://localhost:8000/api/plant-capacity/

EXCEL FILE FORMATS
------------------

Plant Capacity File (0PLANT DEPCAP.xlsx):
  Columns: Plant Name | Installed Capacity (MW) | Dependable Capacity (MW) | Type | Location

Historical Data File (1DATA APAO.xlsx):
  Columns: Date | Plant Name | Generation (MWh) | Availability (%) | Status | Remarks
  Note: Can have multiple sheets for different time periods

TROUBLESHOOTING
---------------
✗ "Plant not found" warnings
  → Ensure plant names match existing plants in the system

✗ Import fails
  → Check that files are in .xlsx format
  → Verify column names match expected format
  → Check Django logs for detailed errors

✗ Database errors
  → Run: python manage.py migrate
  → Ensure database is accessible
