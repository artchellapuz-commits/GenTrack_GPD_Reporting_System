USAGE EXAMPLES:
===============

Success Message:
```javascript
showMessage('success', 'Success!', 'Report created successfully!');
```

Error Message:
```javascript
showMessage('error', 'Error', 'Failed to save report.');
```

Confirmation:
```javascript
showConfirm(
  'Delete Report',
  'Are you sure?',
  async () => {
    // Action to perform if confirmed
    await deleteReport();
  },
  'Delete'
);
```

TECHNICAL DETAILS:
==================

Modal State Variables:
- showMessageModal: Boolean to show/hide message modal
- messageType: 'success', 'error', or 'info'
- messageTitle: Modal title text
- messageText: Modal message (supports HTML)
- showConfirmModal: Boolean to show/hide confirm modal
- confirmTitle: Confirm modal title
- confirmText: Confirm modal message
- confirmButtonText: Text for action button
- confirmCallback: Function to call when confirmed

Helper Functions:
- showMessage(type, title, text): Show message modal
- closeMessageModal(): Close message modal
- showConfirm(title, text, callback, buttonText): Show confirm modal
- confirmAction(): Execute callback and close
- cancelConfirm(): Close without action

CSS Classes:
- .message-modal: Message modal styling
- .confirm-modal: Confirm modal styling
- .modal-header.success/error/info/warning: Colored headers
- .modal-icon: Icon container
- .modal-body: Message content
- .modal-footer: Button container
