HOW TO INSTALL & TEST:
============================================================

STEP 1: INSTALL CHART.JS
Double-click: INSTALL_CHARTJS.bat
OR manually run:
  cd frontend
  npm install chart.js vue-chartjs

STEP 2: RESTART FRONTEND
Press Ctrl+C in your frontend terminal
Then run: npm run serve

STEP 3: TEST IT!
1. Go to Dashboard (http://localhost:8080)
2. Click on AGUS1 or AGUS2 plant card (they have data)
3. Modal opens with beautiful charts!
4. Try clicking AGUS4-7 (no data) - shows "No Data" message
