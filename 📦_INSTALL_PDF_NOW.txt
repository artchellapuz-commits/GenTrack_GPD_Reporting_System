┌──────────────────────────────────────────────────────────────────┐
│  🐛 TROUBLESHOOTING                                              │
└──────────────────────────────────────────────────────────────────┘

  Problem: npm command not found
  Solution: Make sure Node.js is installed
  
  Problem: Permission denied
  Solution: Run Command Prompt as Administrator
  
  Problem: Installation fails
  Solution: Try clearing npm cache:
    npm cache clean --force
    npm install jspdf jspdf-autotable
  
  Problem: Still getting error after install
  Solution: 
    1. Stop dev server (Ctrl+C)
    2. Delete node_modules folder
    3. Run: npm install
    4. Run: npm install jspdf jspdf-autotable
    5. Start dev server: npm run serve


┌──────────────────────────────────────────────────────────────────┐
│  📊 WHAT THESE PACKAGES DO                                       │
└──────────────────────────────────────────────────────────────────┘

  jspdf:
  • Creates PDF documents in JavaScript
  • Generates professional PDF files
  • Client-side PDF generation (no server needed)
  
  jspdf-autotable:
  • Adds table support to jsPDF
  • Creates formatted tables in PDFs
  • Handles pagination automatically


┌──────────────────────────────────────────────────────────────────┐
│  💡 WHY YOU NEED THESE                                           │
└──────────────────────────────────────────────────────────────────┘

  The "Export PDF" button uses these packages to:
  
  ✅ Generate professional PDF reports
  ✅ Include dashboard statistics
  ✅ Create formatted tables with plant data
  ✅ Add page numbers and headers
  ✅ Download directly to your computer
  
  Without these packages, PDF export won't work!
