  ▶️ HOW TO RUN THE NPC REPORTING SYSTEM
═══════════════════════════════════════════════════════════════

QUICK START - 2 TERMINALS NEEDED
=================================

You need to run BOTH backend and frontend at the same time.
Open 2 separate Command Prompt windows.

═══════════════════════════════════════════════════════════════

TERMINAL 1: RUN BACKEND (Django)
=================================

1. Open Command Prompt

2. Navigate to backend folder:
   cd "C:\Users\eladiong\Desktop\OJT Intern\npc-reporting-system\backend"

3. Activate virtual environment:
   venv\Scripts\activate

4. Run Django server:
   python manage.py runserver

✅ Backend will run on: http://localhost:8000
✅ Keep this terminal open!

═══════════════════════════════════════════════════════════════

TERMINAL 2: RUN FRONTEND (Vue.js)
==================================

1. Open ANOTHER Command Prompt (new window)

2. Navigate to frontend folder:
   cd "C:\Users\eladiong\Desktop\OJT Intern\npc-reporting-system\frontend"

3. Run Vue development server:
   npm run serve

✅ Frontend will run on: http://localhost:8080
✅ Keep this terminal open too!

═══════════════════════════════════════════════════════════════

STOP THE SYSTEM
===============

To stop the servers:
- Press Ctrl+C in each terminal window
- Or just close the terminal windows

═══════════════════════════════════════════════════════════════

TROUBLESHOOTING
===============

Problem: "venv is not recognized"
Solution: Make sure you're in the backend folder
         cd "C:\Users\eladiong\Desktop\OJT Intern\npc-reporting-system\backend"

Problem: "python is not recognized"
Solution: Make sure Python is installed
         Check: python --version

Problem: "npm is not recognized"
Solution: Make sure Node.js is installed
         Check: npm --version

Problem: Port already in use
Solution: Close any other programs using ports 8000 or 8080
         Or restart your computer

Problem: Backend runs but frontend shows errors
Solution: Make sure backend is running first
         Check http://localhost:8000/api/plants/
