========================================
⚡ USER ROLES - QUICK REFERENCE
========================================

🔵 VIEWER (Read-Only)
---------------------
WHO: Executives, auditors, stakeholders
CAN: View, search, export reports
CANNOT: Upload, edit, approve, manage
MENU: Dashboard, View Reports, Generate Report

🟢 OPERATOR (Data Entry)
-------------------------
WHO: Plant operators, data encoders
CAN: Upload data, submit water nominations
CANNOT: Approve, delete, manage users
MENU: Dashboard, Upload Excel, View Reports, Generate Report, Water Nomination

🟠 MANAGER (Approval)
---------------------
WHO: Plant managers, supervisors
CAN: Approve submissions, edit/delete data
CANNOT: System admin, manage all users
MENU: Dashboard, Upload Excel, View Reports, Generate Report, Water Nomination, Approval Queue

🔴 ADMIN (Full Access)
----------------------
WHO: IT staff, system administrators
CAN: Everything - full system control
CANNOT: Nothing - complete access
MENU: All menus + Admin Panel + Audit Logs + User Management

WHO SHOULD GET WHICH ROLE?

- Executive management

OPERATOR:
- Plant operators
- Data encoders
- Field staff

- Plant managers

- Team leads

ADMIN:
- IT administrators
- System administrators
- Super users

========================================
SECURITY TIPS
========================================

✅ Start new users as VIEWER
✅ Assign operators to specific plants
✅ One manager per plant minimum
✅ Limit admin access to IT staff only
✅ Change default passwords
✅ Review audit logs regularly
✅ Disable inactive accounts
