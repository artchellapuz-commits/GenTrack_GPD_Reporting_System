WHERE TO FIND GENERATED REPORTS
========================================

QUESTION: After clicking "Run Now", where is the output?

ANSWER: Excel files are automatically generated here:

📂 LOCATION:
  npc-reporting-system/backend/media/automated_reports/

========================================
HOW TO ACCESS THE FILES:
========================================

METHOD 1: File Explorer (Easiest)
  1. Open File Explorer
  2. Navigate to your project folder
  3. Go to: npc-reporting-system\backend\media\automated_reports\
  4. You'll see Excel files like:
     - GENERATION_SUMMARY_20260220_091904.xlsx
     - CAPACITY_FACTOR_20260220_091852.xlsx
     - AVAILABILITY_20260220_091934.xlsx
     - PERFORMANCE_METRICS_20260220_091852.xlsx

METHOD 2: From Project Root
  1. Open: npc-reporting-system folder
  2. Navigate: backend → media → automated_reports
  3. Double-click any .xlsx file to open in Excel

METHOD 3: View in Browser (Coming Soon)
  - Will add download button in next update
  - Click "History" to see list of files
  - Click filename to download

========================================
FILE NAMING FORMAT:
========================================

Files are named with this pattern:
  [REPORT_TYPE]_[DATE]_[TIME].xlsx

Examples:
  GENERATION_SUMMARY_20260220_091904.xlsx
    ↓              ↓        ↓
  Report Type    Date     Time
  
  CAPACITY_FACTOR_20260220_143022.xlsx
  AVAILABILITY_20260220_150315.xlsx
  PERFORMANCE_METRICS_20260220_152045.xlsx

Date format: YYYYMMDD (20260220 = Feb 20, 2026)
Time format: HHMMSS (091904 = 09:19:04 AM)

========================================
WHAT'S IN THE FILES:
========================================

GENERATION_SUMMARY:
  - Date, Plant, Unit
  - Generation (kWh)
  - Operating Hours
  - Capacity Factor
  - Availability Factor

CAPACITY_FACTOR:
  - Plant name
  - Average capacity factor
  - Total generation (MWh)
  - Average operating hours

AVAILABILITY:
  - Plant name
  - Average availability
  - Total forced outage hours
  - Total scheduled outage hours

PERFORMANCE_METRICS:
  - Plant name
  - Capacity (MW)
  - Average capacity factor
  - Average availability
  - Total generation (MWh)
  - Total operating hours
  - Days reported

========================================
HOW TO VIEW EXECUTION HISTORY:
========================================

In the Scheduled Reports page:

  3. Note the filename
  4. Go to automated_reports folder
  5. Open that file

========================================
TROUBLESHOOTING:
========================================

Q: Folder doesn't exist?
A: Run "Run Now" button once to create it

Q: No files in folder?
A: Check backend console for errors
   Make sure you have generation data in database

Q: Can't open Excel file?
A: Make sure you have Excel or compatible software installed
   Try opening with Google Sheets or LibreOffice

Q: File is empty or has no data?
A: Check if you have generation reports in database
   Upload some data first using Upload Excel feature
