═══════════════════════════════════════════════════════════════
   🎯 HOW TO USE IT
═══════════════════════════════════════════════════════════════

1. LOGIN AS ADMIN:
   - Username: admin
   - Password: admin123

2. ACCESS USER MANAGEMENT:
   - Click "User Management" in sidebar under Administration
   - Or go to: http://localhost:8080/user-management

3. CREATE A NEW USER:
   - Click "Create New User" button
   - Fill in username, email, password
   - Select role (Viewer, Operator, Manager, Admin)
   - Click "Create User"

4. EDIT A USER:
   - Click edit icon (pencil) next to user
   - Update email, role, or status
   - Click "Update User"

5. MANAGE USER ACCESS:
   - Click activate/deactivate icon to toggle login access
   - Click delete icon to permanently remove user

   📊 API ENDPOINTS
═══════════════════════════════════════════════════════════════

GET    /api/users/           - List all users
POST   /api/users/           - Create new user
GET    /api/users/{id}/      - Get user details
PUT    /api/users/{id}/      - Update user
PATCH  /api/users/{id}/      - Partial update
DELETE /api/users/{id}/      - Delete user

All endpoints require authentication.
Create/Update/Delete require ADMIN role.
