================================================================================
HOW TO USE
================================================================================

1. GENERATE PSR REPORT:
   - Go to: http://localhost:8080/generate-report
   - Select plants
   - Choose date range
   - Select "Plant Status Report (PSR)"
   - Click "Generate Report"

2. DOWNLOAD PSR TEMPLATE:
   - Go to: http://localhost:8080/upload-excel
   - Click "PSR Template" button
   - Template downloads with all sections

3. GENERATE DAILY STATUS REPORT:
   - Go to: http://localhost:8080/generate-report
   - Select plants
   - Choose SINGLE DATE (Report Date)
   - Select "Daily Plant Status Report"
   - Click "Generate Report"
