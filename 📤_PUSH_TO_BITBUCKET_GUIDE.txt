OPTION 1: AUTOMATIC (EASIEST)
==============================

1. Install Git for Windows:
   - Download: https://git-scm.com/download/win
   - Install with default settings
   - Restart Command Prompt after installation

2. Double-click: PUSH_TO_BITBUCKET.bat
   - It will automatically:
     ✓ Check if Git is installed
     ✓ Initialize repository
     ✓ Add Bitbucket remote
     ✓ Commit all files
     ✓ Push to Bitbucket

3. Enter your Bitbucket password when prompted

═══════════════════════════════════════════════════════════════

OPTION 2: MANUAL (STEP BY STEP)
================================

STEP 1: Install Git
-------------------
Download and install from: https://git-scm.com/download/win

STEP 2: Configure Git
---------------------
Open Command Prompt and run:

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

STEP 3: Navigate to Project
----------------------------
cd "C:\Users\eladiong\Desktop\OJT Intern\npc-reporting-system"

STEP 4: Initialize Repository
------------------------------
git init

STEP 5: Add All Files
----------------------
git add .

STEP 6: Commit
--------------
git commit -m "Initial commit: NPC Reporting System"

STEP 7: Add Remote
------------------
git remote add origin https://artchelintern-admin@bitbucket.org/ojtinternprogram/npc.git

STEP 8: Push to Bitbucket
--------------------------
git branch -M main
git push -u origin main

Enter password when prompted.

AUTHENTICATION
==============

Username: artchelintern-admin

Password Options:
1. Your Bitbucket account password
2. App Password (if 2FA is enabled)

To create App Password:
1. Go to: https://bitbucket.org/account/settings/app-passwords/
2. Click "Create app password"
3. Name: "NPC Reporting System"
4. Permissions: Check "Repositories: Write"
5. Click "Create"
6. Copy the generated password
7. Use this password when pushing

TROUBLESHOOTING
===============

Problem: "git is not recognized"
Solution: Install Git and restart Command Prompt

Problem: "Authentication failed"
Solution: 
- Check username is correct (artchelintern-admin)
- Use App Password if 2FA is enabled
- Verify you have access to the repository

Problem: "Permission denied"
Solution:
- Contact repository admin to grant write access
- Verify repository URL is correct

Problem: "Repository not found"
Solution:
- Check URL: https://bitbucket.org/ojtinternprogram/npc
- Verify repository exists
- Check you have access

═══════════════════════════════════════════════════════════════

VERIFY PUSH SUCCESS
===================

After pushing, verify:

1. Go to: https://bitbucket.org/ojtinternprogram/npc

3. You should see all your files
4. Check the commit message
