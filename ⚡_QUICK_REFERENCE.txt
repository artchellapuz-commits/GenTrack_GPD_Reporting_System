  npm install jspdf jspdf-autotable
  npm run serve

  ⏱️ Time: 30 seconds
  ✅ Required for PDF export


┌──────────────────────────────────────────────────────────────────┐
│  ⌨️  KEYBOARD SHORTCUTS                                          │
└──────────────────────────────────────────────────────────────────┘

  Ctrl+K  →  Open Quick Search
  Ctrl+D  →  Go to Dashboard
  Ctrl+U  →  Go to Upload
  Ctrl+R  →  Go to View Reports
  Ctrl+G  →  Go to Generate Report
  Ctrl+H  →  Go to Home
  ?       →  Show Help (if available)


┌──────────────────────────────────────────────────────────────────┐
│  🎯 DASHBOARD FEATURES                                           │
└──────────────────────────────────────────────────────────────────┘

  [Export PDF]      →  Download dashboard as PDF (red button)
  [Export CSV]      →  Download dashboard as CSV (green button)
  [Refresh]         →  Manually refresh data
  [Auto-refresh]    →  Toggle 30-second auto-refresh

  ⭐ Star Icon      →  Add/remove plant from favorites
  [Compare]         →  Compare multiple plants
  [Export]          →  Export single plant data


┌──────────────────────────────────────────────────────────────────┐
│  🔔 TOAST NOTIFICATIONS                                          │
└──────────────────────────────────────────────────────────────────┘

  Automatically appear for:
  ✅ Success messages (green)
  ❌ Error messages (red)
  ⚠️  Warning messages (yellow)
  ℹ️  Info messages (blue)

  Auto-dismiss after 5 seconds
  Click X to close manually


┌──────────────────────────────────────────────────────────────────┐
│  🔍 QUICK SEARCH                                                 │
└──────────────────────────────────────────────────────────────────┘

  Press Ctrl+K anywhere to open
  
  Search for:
  • Plants (Agus 1, Pulangi 4, etc.)
  • Reports
  • Pages (Dashboard, Upload, etc.)
  
  Navigate:
  ↑↓  →  Move selection
  Enter  →  Go to selected item
  Esc  →  Close search


┌──────────────────────────────────────────────────────────────────┐
│  ⭐ FAVORITES                                                    │
└──────────────────────────────────────────────────────────────────┘

  Click star (⭐) on any plant card
  
  • Star turns yellow when favorited
  • Click again to remove
  • Persists after page refresh
  • Stored in browser localStorage


┌──────────────────────────────────────────────────────────────────┐
│  🔄 AUTO-REFRESH                                                 │
└──────────────────────────────────────────────────────────────────┘

  Click "Auto-refresh OFF" button
  
  • Button turns blue when ON
  • Refreshes every 30 seconds
  • Toast notification on each refresh
  • Click again to turn OFF

┌──────────────────────────────────────────────────────────────────┐
│  🐛 TROUBLESHOOTING                                              │
└──────────────────────────────────────────────────────────────────┘

  PDF not working?
  → npm install jspdf jspdf-autotable

  Features not showing?
  → Refresh page (Ctrl+F5)
  → Check browser console

  Shortcuts not working?
  → Make sure you're not in an input field
  → Ctrl+K works everywhere

  Toast not appearing?
  → Check browser console for errors
  → Try different browser
