STEP 1: INSTALL GIT
-------------------

1.1. Download Git for Windows:
     Go to: https://git-scm.com/download/win
     Download the latest version (e.g., Git-2.43.0-64-bit.exe)

1.2. Install Git:
     - Run the installer
     - Use default settings (just click "Next" for everything)
     - Make sure "Git Bash Here" is checked
     - Complete the installation

1.3. Verify Installation:
     Open a new Command Prompt and type:
     git --version
     
     You should see: git version 2.x.x

═══════════════════════════════════════════════════════════════

STEP 2: CONFIGURE GIT
----------------------

Open Command Prompt and run these commands:

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

Replace with your actual name and email.

STEP 4: INITIALIZE GIT REPOSITORY
----------------------------------

Open Command Prompt in the npc-reporting-system folder:

cd "C:\Users\eladiong\Desktop\OJT Intern\npc-reporting-system"

Then run:

git init

git commit -m "Initial commit: NPC Reporting System"

═══════════════════════════════════════════════════════════════

STEP 5: ADD BITBUCKET REMOTE
-----------------------------

git remote add origin https://artchelintern-admin@bitbucket.org/ojtinternprogram/npc.git

═══════════════════════════════════════════════════════════════

STEP 6: PUSH TO BITBUCKET
--------------------------

For the first push:

git branch -M main
git push -u origin main

You'll be prompted for your Bitbucket password or app password.

For subsequent pushes:

git push

═══════════════════════════════════════════════════════════════

ALTERNATIVE: USE BITBUCKET APP PASSWORD
----------------------------------------

If you have 2FA enabled on Bitbucket, you need an App Password:

1. Go to: https://bitbucket.org/account/settings/app-passwords/
2. Click "Create app password"
3. Name: "NPC Reporting System"
4. Permissions: Check "Repositories: Write"
5. Click "Create"
6. Copy the generated password

When pushing, use this password instead of your account password.

TROUBLESHOOTING:
----------------

Problem: "fatal: repository not found"
Solution: Check the Bitbucket URL is correct
         Make sure you have access to the repository

Problem: "Authentication failed"
Solution: Use an App Password instead of account password
         Check username is correct (artchelintern-admin)

Problem: "Permission denied"
Solution: Make sure you have write access to the repository
         Contact repository admin to grant access
