============================================================
HOW TO USE:
============================================================

STEP 1: Generate files
   Run: GENERATE_ALL_TEST_DATA.bat

STEP 2: Upload to system
   a. Go to Upload page (http://localhost:8080/upload)
   b. Select AGUS4 from dropdown
   c. Upload SAMPLE_AGUS4_30DAYS.xlsx
   d. Wait for success message
   e. Repeat for AGUS5, AGUS6, AGUS7

STEP 3: View results
   a. Go to Dashboard
   b. All 6 plants now have data!
   c. Click on any plant card to see charts
   d. Compare different patterns:
      - AGUS1/AGUS2: Your original data
      - AGUS4: High performance
      - AGUS5: With maintenance gaps
      - AGUS6: Seasonal trends
      - AGUS7: Recent optimal performance

============================================================
TROUBLESHOOTING:
============================================================

Q: Script fails with "No module named 'openpyxl'"
A: Install it: pip install openpyxl

Q: Files not appearing in backend folder
A: Check that you're running from npc-reporting-system folder

Q: Upload fails
A: Make sure backend server is running (python manage.py runserver)

Q: Charts not showing new data
A: Refresh browser (Ctrl+F5) or clear cache
