========================================
QUICK ANSWER: WHERE ARE THE REPORTS?
========================================

Q: After clicking "Run Now", where is the output?

A: Excel files are saved here:
   📂 backend\media\automated_reports\

========================================
FASTEST WAY TO OPEN:
========================================

Double-click: OPEN_REPORTS_FOLDER.bat

This will open the folder in File Explorer.

========================================
MANUAL WAY:
========================================

1. Open File Explorer
2. Go to your project folder
3. Navigate: backend → media → automated_reports
4. You'll see .xlsx files
5. Double-click to open in Excel

WHAT'S IN THE FILES:
========================================

Each Excel file contains:
  - Report header with name and date
  - Data table with columns
  - Generation data from last 30 days
  - Formatted with colors and borders

========================================
HOW TO CHECK:
========================================

1. Click "History" button in Scheduled Reports page
2. You'll see execution details including filename
3. Go to automated_reports folder
4. Find that file
5. Open it

  ✅ Backend generates Excel file
