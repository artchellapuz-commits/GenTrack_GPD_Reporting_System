========================================
HOW TO DOWNLOAD REPORTS FROM FRONTEND
========================================

YES! You can now download reports directly from the UI!

========================================
QUICK STEPS:
========================================

1. Go to: http://localhost:8080/scheduled-reports

2. Click "History" button on any report

3. Modal opens showing all executions

4. Click "Download" button on completed reports

5. Excel file downloads automatically!

========================================

========================================

Execution History Modal:

========================================
FEATURES:
========================================

✅ View all execution history
✅ See execution date/time
✅ Check status (Completed/Failed)
✅ See duration and records processed
✅ View file size
✅ Download with one click
✅ Color-coded status badges
✅ Error messages for failed executions

========================================
STATUS COLORS:
========================================

🟢 Green = COMPLETED (can download)
🔵 Blue = RUNNING (in progress)
🔴 Red = FAILED (see error message)
🟡 Yellow = PENDING (waiting to run)

========================================
FILE DETAILS SHOWN:
========================================

- Execution Date/Time
- Status
- Duration (seconds)
- Records Processed
- File Size (KB/MB)
- Filename
- Download Button (for completed)

========================================
DOWNLOAD PROCESS:
========================================

1. Click "History" button
2. Find the execution you want
3. Click "Download" button
4. File opens in new tab
5. Save to your computer

========================================
WHERE FILES COME FROM:
========================================

Files are served from:
  backend/media/automated_reports/

URL format:
  http://localhost:8000/media/automated_reports/FILENAME.xlsx

========================================
EXAMPLE FILENAMES:
========================================

GENERATION_SUMMARY_20260220_091904.xlsx
CAPACITY_FACTOR_20260220_143022.xlsx
AVAILABILITY_20260220_150315.xlsx
PERFORMANCE_METRICS_20260220_152045.xlsx

========================================
TRY IT NOW:
========================================

1. Open: http://localhost:8080/scheduled-reports
2. Click "History" on "Daily Generation Summary Report"
3. You should see your past executions
4. Click "Download" on any completed execution
5. Excel file downloads!

========================================
TROUBLESHOOTING:
========================================

Q: No executions showing?
A: Click "Run Now" first to generate a report

Q: No download button?
A: Only completed executions have download button

Q: Download not working?
A: Check backend is running on port 8000

Q: File not found?
A: Check backend/media/automated_reports/ folder
