========================================
🔍 WHY APPROVAL QUEUE IS EMPTY
========================================

The Approval Queue shows nominations with status = "SUBMITTED"

Currently EMPTY because:
❌ No water nominations have been submitted yet
❌ Or all nominations are still in DRAFT status
❌ Or all nominations are already APPROVED

========================================
TROUBLESHOOTING
========================================

Problem: Still empty after submitting
--------------------------------------
Check browser console (F12):
- Look for API errors
- Check network tab for /api/water-nominations/ request
- Verify response data

Check backend:
- Is Django server running?
- Check terminal for errors
- Try accessing: http://localhost:8000/api/water-nominations/?status=SUBMITTED

Problem: Can't submit nomination
---------------------------------
- Make sure you're logged in as operator1
- Check that nomination is in DRAFT status
- Look for "Submit" button (not "Approve")

Problem: Don't see Approval Queue menu
---------------------------------------
- Make sure you're logged in as manager1 or admin
- Viewer and Operator cannot see this menu
- Check role in sidebar badge
