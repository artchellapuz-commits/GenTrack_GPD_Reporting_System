THE CORE ISSUE:
  Plant Status Report ≠ Daily Generation Data
  
  Plant Status:
    ✓ Shows current operational status
    ✓ Snapshot at one moment
    ✗ No historical data
    ✗ Cannot generate reports
  
  Generation Data:
    ✓ Shows historical performance
    ✓ Data over time
    ✓ Can calculate metrics
    ✓ Can generate reports

THE SOLUTION:
  Find the SOURCE SYSTEM where daily generation data is recorded:
    • SCADA system (most common)
    • Database system
    • Excel spreadsheets
    • Operator logbooks
    • Energy Management System (EMS)

THE APPROACH:
  1. Understand the difference (use the guides)
  2. Show supervisor what you need (use the template)
  3. Identify the data source (ask the right questions)
  4. Get sample data (test the system)
  5. Establish process (regular updates)

================================================================================
  📊 WHAT YOUR SYSTEM NEEDS
================================================================================

REQUIRED FIELDS (for each unit, each day):
  ✓ Date - Day of operation
  ✓ Unit Number - Which generator (1, 2, 3, etc.)
  ✓ Generation kWh - Energy produced
  ✓ Operating Hours - Hours running (0-24)
  ✓ Availability Hours - Hours available (0-24)
  ✓ Forced Outage Hours - Unplanned downtime
  ✓ Scheduled Outage Hours - Planned maintenance

FORMAT:
  • Excel (.xlsx) file
  • One row per unit per day
  • All fields must be filled
  • Numbers only (no text in number fields)

EXAMPLE ROW:
  2026-01-15 | 1 | 45250 | 22.5 | 24.0 | 1.5 | 0.0
