═══════════════════════════════════════════════════════════════════════
                      GETTING STARTED (5 MINUTES)
═══════════════════════════════════════════════════════════════════════

STEP 1: Run Setup Script
   > SETUP_MONTH_2.bat
   
   This will:
   • Run database migrations
   • Create required directories
   • Collect static files
   • Test commands

STEP 2: Update Frontend Router
   Add to frontend/src/router/index.js:
   
   {
     path: '/scheduled-reports',
     component: () => import('../components/ScheduledReports.vue')
   },
   {
     path: '/analytics',
     component: () => import('../components/AdvancedAnalytics.vue')
   }

STEP 3: Update Sidebar Menu
   Add to Sidebar.vue menu items:
   
   { label: 'Automated Reports', icon: 'pi pi-clock', to: '/scheduled-reports' }
   { label: 'Advanced Analytics', icon: 'pi pi-chart-line', to: '/analytics' }

STEP 4: Add PWA Install Prompt
   In AppLayout.vue:
   
   <PWAInstallPrompt />
   
   Import:
   import PWAInstallPrompt from './components/PWAInstallPrompt.vue';

STEP 5: Configure Email (Optional)
   Update backend/npc_reporting/settings.py:
   
   EMAIL_HOST = 'smtp.gmail.com'
   EMAIL_HOST_USER = 'your-email@gmail.com'
   EMAIL_HOST_PASSWORD = 'your-app-password'

DONE! 🎉

═══════════════════════════════════════════════════════════════════════
                        AUTOMATION SETUP
═══════════════════════════════════════════════════════════════════════

WINDOWS TASK SCHEDULER:
1. Open Task Scheduler
2. Create Basic Task: "NPC Automated Reports"
3. Trigger: Daily at 8:00 AM
4. Action: Start a program
   - Program: python
   - Arguments: manage.py run_scheduled_reports
   - Start in: C:\path\to\backend

LINUX CRON:
Add to crontab:
0 * * * * cd /path/to/backend && python manage.py run_scheduled_reports
